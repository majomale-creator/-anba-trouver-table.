# ANBA — Trouver la table (TEST)

Petit site statique pour GitHub Pages. Les 136 invités et leurs numéros de table TEST sont intégrés dans `app.js`.

## Publication GitHub Pages
1. Créer un nouveau dépôt GitHub, par exemple `anba-trouver-table`.
2. Envoyer à la racine du dépôt les 4 fichiers : `index.html`, `app.js`, `manifest.webmanifest`, `sw.js`.
3. Dans GitHub : **Settings → Pages**.
4. Sous **Build and deployment**, choisir **Deploy from a branch**.
5. Branche : **main** ; dossier : **/(root)** ; puis **Save**.
6. Attendre l'apparition de l'adresse HTTPS GitHub Pages et l'ouvrir dans Safari sur l'iPhone.
7. Autoriser le microphone si Safari le demande.

IMPORTANT : GitHub Pages fournit bien HTTPS, mais la reconnaissance vocale dépend aussi de ce que Safari/iOS expose au site. Si le bouton affiche « MICRO NON DISPONIBLE », ce n'est pas un problème d'HTTPS ; il faudra changer de méthode de reconnaissance.
